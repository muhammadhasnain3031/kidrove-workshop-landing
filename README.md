# 🚀 Kidrove Workshop Landing Page

A modern, responsive, and high-conversion **AI & Robotics Workshop Landing Page** built with **Next.js 15, Tailwind CSS, and Framer Motion**.

This project is designed for **lead generation, student registrations, and workshop marketing campaigns** with a clean SaaS-style UI.

---

## ✨ Features

- ⚡ Next.js 15 App Router architecture
- 🎨 Modern SaaS-inspired UI design
- 🎬 Smooth animations using Framer Motion
- 📱 Fully responsive (mobile-first)
- 🧠 Enquiry form with API integration
- 🔥 FAQ accordion system
- 🚀 High-performance optimized layout

---

## 🧰 Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Node.js (API Routes)
