# 🚀 Next.js App (Workshop / Landing Project)

A modern, responsive web application built with **Next.js 15**, **React**, and **Tailwind CSS**, designed for workshop landing pages, registration systems, and scalable SaaS UI.

---

## ✨ Features

- ⚡ Built with Next.js App Router
- 🎨 Modern responsive UI with Tailwind CSS
- 🎬 Smooth animations (Framer Motion ready)
- 🧠 API integration support (Enquiry form)
- 📱 Mobile-first responsive design
- 🧩 Component-based architecture
- 🚀 Optimized font loading with `next/font`

---

## 📦 Tech Stack

- Next.js 15+
- React
- TypeScript
- Tailwind CSS
- Framer Motion (for animations)
- Node.js API Routes
